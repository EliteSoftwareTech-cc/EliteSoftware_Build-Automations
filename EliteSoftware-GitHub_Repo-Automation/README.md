# EliteSoftware-GitHub_Repo-Automation

**Information-First Engineering. Absolute System Purity.**

Welcome to the official source repository for **EliteSoftware-GitHub_Repo-Automation**. 
This project serves as the digital station for EliteSoftware's engineering initiatives, providing a dedicated CLI tool (`EliteGitHubAutomator.exe`) for standardizing GitHub repository interactions across all projects.

- 📖 [Continuous Changelog](changelog.md)

## 🚀 Mission Protocol
To eliminate redundant GitHub command-line operations (initialization, auto-commits, and complex dual-architecture release publishing) by consolidating them into a single, highly reusable executable. 

### Core Focus Areas:
- **System Purity:** Zero-compromise approach to system telemetry and performance.
- **Automation:** Standardizing repo creation (defaults to private) and release deployment natively.
- **Modern Hybridization:** Blending classic UX depth with PowerShell 7 and `gh` CLI integrations.

## 🛠️ Workstation Profile 
- **Automation:** Native C++ (Compiled via `g++` / MinGW)
- **Frameworks:** GitHub CLI (`gh`)
- **System Modding:** Native Git Integration
- **Languages:** C++

## 📡 Deployment Information
This site/utility is designed for high-density deployment. 

### Local Development 
1. Run `build.ps1` to compile `EliteGitHubAutomator.exe` natively using `g++`.
2. Use `EliteGitHubAutomator.exe init -Name "MyRepo"` to generate a new project.
3. Use `EliteGitHubAutomator.exe commit` to auto-commit and push.
4. Use `EliteGitHubAutomator.exe release -Version "1.0.0"` to deploy.
